# Ejemplos SOLID en C#

Esta carpeta contiene un ejemplo pequeno para cada principio SOLID:

- `01_SingleResponsibility.cs`: Single Responsibility Principle.
- `02_OpenClosed.cs`: Open/Closed Principle.
- `03_LiskovSubstitution.cs`: Liskov Substitution Principle.
- `04_InterfaceSegregation.cs`: Interface Segregation Principle.
- `05_DependencyInversion.cs`: Dependency Inversion Principle.

Para ejecutar los ejemplos:

```bash
cd solid
dotnet run
```

Cada archivo esta separado para que puedas estudiar un principio a la vez.
