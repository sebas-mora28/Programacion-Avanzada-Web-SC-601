# Ejercicio 3 — Procesamiento CSV

Proyecto de consola independiente (.NET 8) con CsvHelper.

## Actividad
- Leer `products.csv` y crear una lista de objetos `Product`.
- Filtrar registros con `Price > 30` (estrictamente mayor).
- Escribir `filtered_products.csv`, conservando encabezados `Id,Name,Price`.

## Ejecutar
```bash
dotnet restore
dotnet run
```
Complete los métodos `TODO` de `ProductCsvService` y habilite la llamada comentada de `Program.cs`.
